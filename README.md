# eastcoast-engineering-terraform

**Initialize**
```
make init ENV=dev
make init ENV=prod
```

**Plan changes**
```
make plan ENV=dev
make plan ENV=prod
```

**Apply changes**
```
make apply ENV=dev
make apply ENV=prod
```

**Destroy environment**
```
make destroy ENV=dev
make destroy ENV=prod
```

**Format + validate**
```
make fmt
make validate ENV=dev
```
